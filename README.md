# Wardrobe Bot

## AI платформа автоматизации мебельного производства

Wardrobe Bot это цифровая система автоматизации подготовки мебельных
изделий от идеи до производства.

Платформа объединяет Telegram конструктор, WebApp конфигуратор WAB,
подготовку производственной документации и AI визуализацию будущего
изделия.

Проект создан для объединения клиента, конструктора и производства в
одном цифровом процессе.

## О проекте

Wardrobe Bot помогает превратить описание будущего шкафа в
структурированный производственный проект.

Система позволяет:

• Формировать параметры изделия.

• Создавать спецификацию шкафа.

• Подготавливать техническую документацию.

• Создавать карту раскроя.

• Получать визуальное представление будущего изделия.

## Основные возможности

## Telegram конструктор

Telegram бот используется как удобный интерфейс для пошагового
формирования изделия.

Через него задаются:

• Размеры шкафа.

• Количество секций.

• Внутреннее наполнение.

• Фасады.

• Материалы.

• Фурнитура.

• Крепёж.

После заполнения данные передаются в следующие модули системы.

## WAB WebApp конфигуратор

WebApp конфигуратор используется для расширенной работы с параметрами
изделия.

Возможности:

• Настройка конфигурации шкафа.

• Управление параметрами заказа.

• Подготовка данных для технических модулей.

• Контроль характеристик будущего изделия.

## Производственная документация

Система формирует данные для дальнейшего производства:

• Технический чертёж.

• Детали изделия.

• Карту раскроя.

• PDF документацию.

• Структурированную спецификацию заказа.

## AI визуализация шкафа

AI визуализация позволяет получить изображение будущего изделия до
начала производства.

Процесс построен через несколько инструментов:

• Gemini используется как AI модель для работы с визуальными задачами и
генерацией вариантов представления изделия.

• ProxyAPI используется как промежуточный слой для подключения AI
сервисов через единый интерфейс.

• AI обработка позволяет создавать первый вариант рендера.

• Текстовые команды позволяют изменять результат и уточнять внешний вид.

• Голосовые команды позволяют передавать изменения через описание.

В результате пользователь получает визуальное представление будущего
шкафа до запуска производства.

Проект разработан с использованием:

• WebApp технологий для конфигуратора.

• JavaScript для клиентской части.

• SQLite для хранения данных.

• PDF генерации для производственной документации.

• Gemini AI для визуальных задач.

• ProxyAPI для интеграции AI сервисов.

• Git и GitHub для управления версиями проекта.
